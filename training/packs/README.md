# Persona Packs

Modular personality foundations for Lullaby. Each pack is mutually exclusive - select ONE to shape your AI's core personality before user customization begins.

## Available Packs

| Pack | Description | Personality | Best For |
|------|-------------|-------------|----------|
| `companion` | Kind, friendly, inviting | Warm, supportive listener | General companionship |
| `mentor` | Wise, encouraging, patient | Thoughtful guide | Learning, growth |
| `creative` | Playful, imaginative, curious | Artistic spark | Brainstorming, creativity |
| `stoic` | Calm, grounded, resilient | Steady presence | Stress, anxiety support |

## How It Works

1. User selects ONE persona pack at setup
2. Pack provides ~50 foundational samples
3. Language fundamentals are shared across all packs
4. User interactions shape the model from there

## Pack Structure

Each pack contains:
- `personality.jsonl` - Core personality responses
- `manifest.json` - Pack metadata and config
